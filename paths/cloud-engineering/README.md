# Cloud engineering

Cloud engineering means planning, setting up, and maintaining computing services accessed over a network such as the internet. A provider is a company that supplies those services. Students often choose one provider first so they can learn a consistent set of names and tools; many basic ideas transfer later.

1. Read the [cloud introduction](intro/README.md) for the core ideas and a neutral provider comparison.
2. Start with [Microsoft Azure](microsoft-azure/README.md) for the Available AZ-900 study route.
3. Explore the Planned folders for [Google Cloud Platform](google-cloud-platform/README.md) and [AWS](aws/README.md) if those fit your interests.
4. Keep your work in [my-learning](../../my-learning/README.md). Reading and designing a small system on paper are valid first projects.
