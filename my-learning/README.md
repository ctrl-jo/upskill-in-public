# My learning workspace

This is your personal workspace in your own copy of the kit. Your notes, logs, and projects go here. The folders in `paths/` are guides and examples to read.

## Optional layout

This layout is a suggestion, not a set of folders already created for you. Your first log can go directly in `my-learning/`.

```text
my-learning/
  README.md
  daily-logs/
  notes/
  projects/
  progress-tracker.md
```

## Copy a template on GitHub

1. Open your own repository, not `ctrl-jo/upskill-in-public`. Open `templates`, then `daily-log.md`.
2. Select **Code** within the file view to see the Markdown text, or select **Raw**. Copy the entire file text, including its headings. If you used Raw, use your browser's Back button afterward.
3. Return to your repository's main file list by clicking its name above the files. Open `my-learning`.
4. Select **Add file**, then **Create new file**. Name the file `2026-10-16-daily-log.md`, replacing the date with today's date in year-month-day order. Use a different name if that file already exists.
5. Paste the copied text into the large editor. Replace the bracketed fields with your own words; it is fine to leave unfinished sections for later.
6. Select **Commit changes**. A commit is a saved version of your changes. Enter a short message such as `Add my first daily log`, keep the option to commit directly to the current branch, then select **Commit changes** again.
7. To update the log later, open it, select the pencil icon (**Edit this file**), change the text, and repeat step 6.

## Copy a template on your computer

1. Open your extracted or cloned kit folder. Open `templates`, right-click `daily-log.md`, and select **Copy**.
2. Go back to the kit folder, open `my-learning`, right-click in an empty space, and select **Paste**.
3. Rename the pasted file `2026-10-16-daily-log.md`, replacing the date with today's date. Keep the `.md` ending. If your computer hides file extensions, change only the visible name and do not add a second `.md`.
4. Open the copied file in your text editor, replace the bracketed fields, and select **File > Save**.
5. Repeat these steps with another [template](../templates/README.md) when you need it. These local files are not automatically uploaded to GitHub.

## Add the optional layout later

1. On your computer, create `daily-logs`, `notes`, and `projects` folders inside `my-learning` using your file manager's **New folder** action.
2. On GitHub, create a file with a name such as `daily-logs/2026-10-16-daily-log.md` while inside `my-learning`. The slash creates the folder when you save the file.
3. Copy the progress tracker template into `my-learning` and name it `progress-tracker.md`.
