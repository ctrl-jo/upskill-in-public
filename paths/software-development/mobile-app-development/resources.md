# Mobile app development resources

[Android Basics with Compose](https://developer.android.com/courses/android-basics-compose/course) — Free official Android lessons; Compose is a tool for building app screens.

[Swift learning resources](https://www.swift.org/getting-started/) — Official introduction to the Swift language.

[Apple Develop in Swift](https://developer.apple.com/tutorials/develop-in-swift) — Free official app lessons; required hardware and tools vary by lesson.

[Flutter learning pathway](https://docs.flutter.dev/learn/pathway) — Official Dart and Flutter route for beginners.

[React Native introduction](https://reactnative.dev/docs/getting-started) — Official route for learners with JavaScript knowledge; React basics help.

[GitHub Hello World](https://docs.github.com/en/get-started/using-github/hello-world) — First repository and saved changes.

The lessons are free to read. Required hardware, paid services, and app-store publishing are separate; none is needed to complete the first planning task.
