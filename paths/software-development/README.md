# Software development

Software development means writing and improving instructions that computers follow. This group includes websites and phone apps.

1. Start with [web development](web-development/README.md) for an Available route through JavaScript, a language used to make pages interactive.
2. Explore [mobile app development](mobile-app-development/README.md) if phone apps interest you. Its beginner route is Available, with Android, iOS, and cross-platform choices.
3. Save your own practice in [my-learning](../../my-learning/README.md).
