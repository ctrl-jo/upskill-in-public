# Web development roadmap

This is an original suggested route, not a fixed schedule. The first step is enough for your first short session.

1. Learn HTML (HyperText Markup Language), the marks that give a page its structure. Open the MDN beginner lessons from [resources](resources.md), read about headings and paragraphs, and write a heading and a paragraph about yourself in a practice file or the lesson's editor. Check that you can explain which part is the heading.
2. Learn CSS (Cascading Style Sheets), rules that control a page's appearance. Add a color, spacing, and a readable text size to your page. Check that the text still fits a narrow browser window.
3. Learn JavaScript, a programming language that adds behavior. Practice variables (named values), conditions (choices), loops (repeated actions), and functions (reusable instructions). Use the [JavaScript guide](javascript/README.md), then make a button change some text.
4. Practice arrays (lists of values) and objects (groups of named values). Build a small word counter or reading list. Try an empty input and explain what the program does.
5. Learn Git, a tool that records file changes. In your own project, save a first commit (a recorded version), change one line, and inspect the difference. Then practice sending your own project to GitHub using a beginner Git guide in [curated links](../../../resources/curated-links.md).
6. Explore a framework, a set of tools and patterns for building apps, only after you can make a small page yourself. Choose one from a current beginner resource and rebuild a small part of your project. Explain what the framework helped with.
7. Record what works, what needs improvement, and how someone can run your project in a [mini-project page](../../../templates/mini-project.md). Share it when ready.
