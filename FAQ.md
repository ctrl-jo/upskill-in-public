# Frequently asked questions

## Do I need to know Git?

No. Git is a tool for tracking changes to files. The template and ZIP options in [Getting Started](GETTING-STARTED.md) work without Git commands.

## Do I need to install anything?

No installation is needed to read the kit or write notes on GitHub. A ZIP copy needs a text editor, which most computers already have. Some later programming exercises need tools; their linked lessons explain setup. Reading cloud material does not require a paid cloud account. Cloud services and certification exams may cost money and are optional.

## Which path should I pick first?

Web development has an available roadmap and free beginner resources. Azure also has an available study route. The [choosing guide](start-here/choosing-your-path.md) helps you decide based on your interests.

## Can I study more than one path?

Yes. One path at a time is usually easier to manage. Switching later is welcome.

## What is a roadmap?

A roadmap is a suggested order of topics and small practice tasks. It is a guide, not a deadline or a guarantee of a job.

## Where do I save my notes?

The `my-learning/` folder in your own copy is your workspace. The [copy instructions](my-learning/README.md) explain how to save a first log.

## Can I share my notes publicly?

Yes, your own explanations and projects are welcome. Paid course pages, answer keys, and other people's content are not yours to republish. Links to the original source are fine. Passwords, access keys, student IDs, and private information do not belong in public notes.

## Can I use this for school or self-study?

Yes. The kit is under the [MIT license](LICENSE). Your school's rules still apply to assignments. Linked resources keep their own licenses and terms.

## How do I suggest a new path?

1. Sign in to GitHub and open the original repository's [Issues page](https://github.com/ctrl-jo/upskill-in-public/issues).
2. Select **New issue**, then **Suggest a path** (and **Get started** if shown).
3. Fill in the path name, why it matters, linked resources, and target audience.
4. Select **Submit new issue**.

## What do the Available and Planned labels mean?

**Available** means a usable starting roadmap and resource links exist. It does not mean every example project is finished. **Planned** means introductory material or placeholders exist, but the full learning route is not ready.

## Why are some folders empty or marked Coming soon?

They reserve a consistent place for future examples. A `.gitkeep` is an empty placeholder file used to keep a folder in Git; it is not a lesson. Notes folders also have a README, so the placeholder is included for consistency. You can start with an Available roadmap while examples are being added.
