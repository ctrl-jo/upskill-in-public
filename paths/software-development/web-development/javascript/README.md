# JavaScript basics

JavaScript is a programming language used to make web pages respond to people. Basics include variables (named values), conditions (choices), loops (repeated actions), functions (reusable instructions), arrays (lists), and objects (groups of named values).

1. Follow the JavaScript steps in the [web roadmap](../roadmap.md) and choose a lesson from [resources](../resources.md).
2. Read [notes](notes/README.md) for the purpose of the example-notes folder.
3. Open [projects](projects/README.md) for planned mini-project examples.
4. Write your own notes and practice in [my-learning](../../../../my-learning/README.md), even while examples are Coming soon.
