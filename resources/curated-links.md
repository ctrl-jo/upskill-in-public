# Curated learning links

These official and community resources are free to read. Optional certificates, app-store publishing, hardware, or cloud service usage may have costs. Linked material belongs to its creators.

## GitHub and Git

[GitHub: Hello World](https://docs.github.com/en/get-started/start-your-journey/hello-world) — Official introduction to repositories and saving changes.

[Git book](https://git-scm.com/book/en/v2) — Free book about tracking and sharing file changes.

## Web development

[MDN learning material](https://developer.mozilla.org/en-US/docs/Learn_web_development) — Guides to web page structure, styling, and programming.

[freeCodeCamp](https://www.freecodecamp.org/learn/) — Free community-built programming lessons and exercises.

## Mobile app development

[Android Basics with Compose](https://developer.android.com/courses/android-basics-compose/course) — Official beginner Android course.

[Swift getting started](https://www.swift.org/getting-started/) — Official introduction to Swift.

[Develop in Swift](https://developer.apple.com/tutorials/develop-in-swift) — Official lessons for building apps with Apple's tools.

## Cloud engineering

[Microsoft Learn: Azure](https://learn.microsoft.com/en-us/training/azure/) — Free Azure learning material.

[AZ-900 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-900) — Official exam scope and study links.

[Azure documentation](https://learn.microsoft.com/en-us/azure/) — Official Azure service reference.

[Microsoft Q&A](https://learn.microsoft.com/en-us/answers/) — Community help and explanations.

[Google Cloud documentation](https://cloud.google.com/docs) — Official Google Cloud service guides.

[AWS documentation](https://docs.aws.amazon.com/) — Official AWS service guides.

[React Learn](https://react.dev/learn) — Optional component-based frontend learning after JavaScript.

[Node.js Learn](https://nodejs.org/en/learn) — JavaScript outside the browser for backend practice.

[PostgreSQL tutorial](https://www.postgresql.org/docs/current/tutorial.html) — Relational data and SQL basics.
