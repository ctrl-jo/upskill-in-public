# Learning paths

A path is a suggested learning route, not a full course. **Available** means a usable starting roadmap and resource links exist; it does not mean a complete set of lessons or projects. **Planned** means the starting route is not ready yet.

Web development and Azure have the most supporting material in this kit. Mobile development, AWS, and Google Cloud provide lighter starting guides. Shared example projects and deeper role-focused material are still being added.

## How every path is organized

| Item | Purpose |
| --- | --- |
| README.md | What the path is, who it is for, and how to use it. |
| roadmap.md | Foundations, checkpoints, a choice of direction, a small project, and role-focused next steps. |
| resources.md | Links to outside learning material. |
| Optional topic folders | Notes and examples about a smaller topic, such as JavaScript or AZ-900. |

The [software development](software-development/README.md) and [cloud engineering](cloud-engineering/README.md) folders group related paths. The cloud intro and topic folders provide background; they are not separate full paths.

1. Open one Available folder from the table.
2. Read its README and follow its numbered steps.

## Suggest a path

1. Read the [Suggest a path template](../.github/ISSUE_TEMPLATE/suggest-path.md).
2. Follow the [contribution steps](../CONTRIBUTING.md) to send your suggestion.

## From beginner to a role

1. Start with your path's foundations and one free resource.
2. Use its checkpoints to decide when to continue; fixed monthly deadlines are not required.
3. Choose one role or platform branch and complete its small project.
4. Share your own evidence of learning and choose a next step. Cloud fundamentals study is Available for Azure, AWS, and Google Cloud; detailed role-based certification routes are Planned — Coming soon.

New paths follow the [standard roadmap format](../CONTRIBUTING.md) so the same learning routine works across the kit.
