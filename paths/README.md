# Learning paths

A path is a suggested learning route. Available paths have a usable starting roadmap and resource links. Planned paths are not complete yet.

| AWS | [cloud-engineering/aws](cloud-engineering/aws/) | Planned |

## How every path is organized

| Item | Purpose |
| --- | --- |
| README.md | What the path is, who it is for, and how to use it. |
| roadmap.md | A suggested order of topics and practice tasks. |
| resources.md | Links to outside learning material. |
| Optional topic folders | Notes and examples about a smaller topic, such as JavaScript or AZ-900. |

The [software development](software-development/README.md) and [cloud engineering](cloud-engineering/README.md) folders group related paths. The cloud intro and topic folders provide background; they are not separate full paths.

1. Open one Available folder from the table.
2. Read its README and follow its numbered steps.
